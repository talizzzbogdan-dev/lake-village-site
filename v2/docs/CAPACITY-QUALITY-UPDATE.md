# Обновление 26 ноября: вместимость и изображения

Вместимость стеклянной оранжереи изменена с 100 до 120 гостей: HTML, RU/EN-тексты и плашка, числовой счётчик, RU/EN-карточка генплана.

Восстановлена детализация изображения ресторанного холла. Одна обработка существующего изображения с сохранением композиции, двух этажей, общего силуэта здания и закатного освещения. Результат подключён как v-restaurant-enhanced.webp; исходный v-restaurant.webp сохранён.

Для шести свежих изображений событий сделаны WebP-версии hq из исходных PNG с качеством 91 вместо 85 при прежней ширине 1440 px. Дополнительная нейросетевая обработка этих шести изображений не выполнялась. Их суммарный размер вырос примерно с 2,2 до 2,8 МБ; lazy loading сохранён.

Использована одна генерация для ресторана, остальные изменения качества — экспорт из исходников с меньшими потерями. Новые архитектурные объекты не добавлялись. Это концептуальные визуализации; надписи об этом сохранены.
